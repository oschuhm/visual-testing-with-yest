# Visual Testing with Yest

Design quality early through visual workflows instead of testing it at the end.

---

## Overview

This repository provides sample **Yest projects** showcasing visual test analysis and design using:

- Visual workflows  
- Decision tables  
- Structured design data  

The examples demonstrate how complex test scenarios can be modeled transparently and consistently using a model-based approach instead of traditional Excel-based test case design.

The repository is intended for:

- Test Analysts  
- QA Leads  
- Quality Engineers  
- Anyone interested in visual, model-driven test design  

---

## What You Will Find Here

Each sample includes:

- A visual workflow model  
- Associated decision tables  
- Design data structures  
- UI flow scenarios  
- Interface testing scenarios  

The samples cover multiple complexity levels — from simple flows to more advanced modeling approaches.

---

## Purpose

The goal of this repository is to demonstrate how:

- Quality can be **designed early**
- Stakeholders can align on test logic visually
- Decision coverage becomes explicit and transparent
- Test design moves from static test cases to structured models

These samples can be used for:

- Learning visual test design with Yest  
- Internal QA workshops  
- Demonstrations and conference sessions  
- Experimentation with model-based approaches  

---

## Philosophy

Quality should not be tested in at the end.

Instead, it should be:
- Modeled
- Structured
- Reviewed visually
- Generated consistently

This repository illustrates how visual workflows and decision tables help make test logic explicit, reviewable, and scalable.
